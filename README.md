## Why UWorld Player · 왜 유월드 플레이어인가

Most people juggle a video player, a music app, a photo viewer, a PDF reader, an archive tool and a file manager — each with its own look and its own ads. UWorld Player puts all of them into **one clean app with no ads**, so you can open almost any file you have and get straight to it.

The desktop version (Windows · macOS) is built for big screens and a mouse: a tabbed workspace, a ribbon toolbar, hardware-accelerated video, a full PDF notebook and handy tools such as screen capture, text-to-speech and duplicate cleanup. The same app is also available on Android, iPhone and iPad.

동영상 플레이어, 음악 앱, 사진 뷰어, PDF 리더, 압축 프로그램, 파일 관리자를 따로따로 쓰고 계신가요? 유월드 플레이어는 이 모든 것을 **광고 없는 앱 하나**에 담았습니다. 가지고 있는 거의 모든 파일을 바로 열어 쓸 수 있습니다.

데스크톱판(Windows · macOS)은 큰 화면과 마우스에 맞춰 상단 탭·리본 메뉴, 하드웨어 가속 영상 재생, PDF 노트, 화면 캡처, 텍스트 읽어주기, 중복 파일 정리 같은 도구를 제공합니다. 같은 앱을 Android, iPhone, iPad 에서도 쓸 수 있습니다.

## Features · 주요 기능

### 🎬 Video & music player · 영상·음악 재생
- Plays almost every video and audio format with hardware decoding, subtitles, speed control and resume.
  거의 모든 영상·음악 형식을 하드웨어 가속으로 재생하고, 자막·배속·이어보기를 지원합니다.
- Folder-based media library with thumbnails, sorting and continuous play.
  폴더별 미디어 라이브러리(썸네일·정렬·연속 재생)를 제공합니다.

### 🖼️ Photos & image editor · 사진 보기·이미지 편집
- Fast image viewer including HEIC photos from iPhone.
  아이폰 HEIC 사진까지 빠르게 보여 줍니다.
- Crop, rotate, draw, add text and export as PNG/JPG.
  자르기·회전·그리기·글자 넣기 후 PNG/JPG 로 저장합니다.

### 📄 PDF notebook · PDF 노트
- Read PDFs with smooth scrolling, search, thumbnails and side-by-side view of two PDFs.
  부드러운 스크롤, 검색, 썸네일, 두 PDF 나란히 보기를 지원합니다.
- Write on pages with pen, highlighter, eraser and sticky notes — saved automatically.
  펜·형광펜·지우개·메모로 필기하고 자동 저장합니다.
- Page editing: reorder, rotate, duplicate, delete, extract pages, insert other PDFs or images, and compress.
  페이지 순서 변경·회전·복제·삭제·추출, 다른 PDF·이미지 끼워 넣기, 압축을 할 수 있습니다.

### 📸 Screen capture · 화면 캡처
- Capture any monitor, all monitors, an open window or a dragged area — with timer and cursor options.
  모니터 하나·전체 모니터·열린 창·드래그 영역을 캡처하고, 타이머·마우스 커서 포함 옵션을 제공합니다.

### 🗣️ Text-to-speech reader · 텍스트 읽어주기(TTS)
- Load .txt or Markdown files and have them read aloud, with repeat and next-file play.
  .txt·마크다운 파일을 불러와 소리로 읽어 주며, 반복·다음 파일 재생을 지원합니다.

### 🗂️ File explorer & archives · 탐색기·압축
- Browse, copy, move, rename and delete files; open and extract zip, 7z, rar, tar and more.
  파일 탐색·복사·이동·이름 변경·삭제, zip·7z·rar·tar 등 압축 해제를 지원합니다.

### 🧹 Handy tools · 편리한 도구
- Duplicate finder, disk analyzer, folder sync, memo pad and system information.
  중복 파일 찾기, 디스크 분석, 폴더 동기화, 메모장, 시스템 정보를 제공합니다.

### 🌐 Network · 네트워크
- SFTP, SSH terminal, shared folders (SMB/NAS) and remote desktop (VNC).
  SFTP, SSH 터미널, 공유 폴더(SMB/NAS), 원격 데스크톱(VNC)에 접속합니다.

### 🌏 10 languages · 10개 언어
- Korean, English, Chinese, Japanese, Spanish, French, German, Portuguese, Russian and Italian.
  한국어·영어·중국어·일본어·스페인어·프랑스어·독일어·포르투갈어·러시아어·이탈리아어를 지원합니다.

## Install · 설치 안내

### Windows

**Requirements · 사양**: Windows 10 / 11 (64-bit).

1. Download **`UWorldPlayer-<version>-windows-x64-setup.exe`** from the [latest release](https://github.com/UWorld-Group/uworldplayer/releases/latest).
   [최신 릴리스](https://github.com/UWorld-Group/uworldplayer/releases/latest)에서 설치 파일을 내려받습니다.
2. Run it and follow the installer (administrator permission is requested because the app is installed for all users). The installer and every program file are code-signed by **유월드 (UWorld)**.
   실행하면 설치가 진행됩니다(모든 사용자용으로 설치되므로 관리자 권한을 묻습니다). 설치 파일과 프로그램 파일은 모두 "유월드" 이름으로 서명되어 있습니다.
3. *(Optional)* Verify the file with `SHA256SUMS.txt` from the same release:
   *(선택)* 같은 릴리스의 `SHA256SUMS.txt` 로 파일이 변조되지 않았는지 확인할 수 있습니다.
   ```powershell
   Get-FileHash .\UWorldPlayer-<version>-windows-x64-setup.exe -Algorithm SHA256
   ```

You can also install it from the [Microsoft Store](https://apps.microsoft.com/detail/XP894K8V5D8QWK).
[Microsoft Store](https://apps.microsoft.com/detail/XP894K8V5D8QWK) 에서도 설치할 수 있습니다.

### macOS (DMG)

**Requirements · 사양**: macOS 12 or later, Apple silicon or Intel.

1. Download **`UWorldPlayer-<version>-macos-universal.dmg`** from the [latest release](https://github.com/UWorld-Group/uworldplayer/releases/latest) and open it.
   최신 릴리스에서 DMG 를 내려받아 엽니다.
2. Drag **UWorld Player** onto **Applications**. The app is signed with UWorld's Developer ID and **notarized by Apple**.
   **UWorld Player** 를 응용 프로그램 폴더로 끌어다 놓습니다. 유월드 Developer ID 서명과 Apple 공증을 받은 앱입니다.
3. Prefer automatic updates? Install from the [Mac App Store](https://apps.apple.com/app/id6814982809).
   자동 업데이트를 원하시면 Mac App Store 판을 설치하세요.
